字符数按原文区间计数，不计多段拼接分隔符；F004155 命中为两处各 20 字符，不能只选其一。补充层可能与命中重叠，表内两列不能相加当成唯一原文长度。机器对比和实际返回文本见 [comparison.jsonl](comparison.jsonl)。

旧 E02 的 F004090 P2/C002 实际返回 645 字符、F004155 P2/Q009 实际返回 519 字符，与错误记录相符；旧 E01 的 D1 已分别改为 85 字符和 131 字符。两轮实际返回均已回读并留存，在 [historical_return_observations.jsonl](historical_return_observations.jsonl) 中共 32 条观测。它们是历史数据，本轮没有再次调用模型评分或声称复现旧指标。其他同批旧范围取冻结 V2 的上下文字段，具体来源已在每行声明。

F004155 的第2行是机构合同外利益，第7行是个人及其职务，另列销售误导。两个位置和表行只证明各自原文范围，不能据此断言同一实施人、同案责任或整表统一主体。F006493、F006220、F000269 的共同案由也未因分层而解决归属。所有现有候选关联均继续待核，其他 unit 不自动继承本次范围复核。

完整性方面，9639 当前稿的规范 JSON SHA、解压后行号、候选身份及源 SHA 全部一致；9639 份规范源文与公开副本的 97 个来源分片逐份一致。65475 个结构化单元与 45403 个原文单元的投影文件 SHA 和登记原句区间检查通过。5 份修正严格对应 33 个旧稿指纹；排名文本及返回上下文未变，但 9 个结构化修正投影的关联仍用局部 ID，故禁止整行替换，详见 [compatibility_audit.json](compatibility_audit.json)。

测试先于实现：首轮 11 项因加载器不存在按预期失败，见 [tests_red.txt](tests_red.txt)；实现后通过。随后新增跨 unit/span 重复 ID、span 来源指纹不符等防护测试，其中两个先真实失败，见 [tests_red_hardening.txt](tests_red_hardening.txt)，修复后最终 14 项全部通过，见 [tests_green.txt](tests_green.txt)。初次测试数据曾因 Windows 自动换行导致文件 SHA 与字符串 SHA 不同，已把测试指纹改为实际文件字节计算，正式加载器始终按实际字节校验。

实际包测试覆盖 19 个 unit 的 57 次分层读取、57 个 span 的读取及原文比对，以及 62 次版本、未知 ID 和错误区间拒绝。源码和测试均随本目录提供，可直接运行：

```powershell
python 'test_evidence_loader.py'
```

`evidence_loader.py` 是导入式类，验证以测试和 [loader_verification.json](loader_verification.json) 的实际包检查为准。全量审计与实际包检查的复跑脚本位于工作区 `work/finrisk_kb_improvements_20261018/handoff_scope/build_handoff.py`、`finalize_handoff.py`，先全量审计再执行交接包收尾；两者仅向本轮独立输出目录写入。

本轮模型自行阅读全文、比较范围和标注限制，不是专家批准。来源核验范围限已导出的 UTF-8 原文，未把原网页、原 PDF 或文本提取一致性改称已核验；两份法条样例仅核对既有阅读快照区间，当前效力及历史行为时点适用仍待专门核验。样例非随机，不提供全库质量率、召回提升或 Agent 判断准确率。

当前稿唯一入口仍为 `outputs/FinRisk_知识库V2.1轻量收尾_20261015/effective_candidates.jsonl.gz` 的 `draft`。同目录 `file_index.jsonl` 的 `line` 是解压后 1 起行号，不能作为 gzip 字节偏移。案例内容、检索投影、法规条文、规则解释及本轮范围覆盖的版本分别保存在 [handoff_manifest.json](handoff_manifest.json) 和 [version_lock.json](version_lock.json)。每类均应同时绑定指纹，不能只替换版本名称。

33 个单元的安全重绑定要求在 [projection_candidate_rebinds.jsonl](projection_candidate_rebinds.jsonl)，关联差异映射在 [projection_patch_compatibility.jsonl](projection_patch_compatibility.jsonl)。使用原单元的稳定 ID 和关联，把 `candidate_sha256` 绑定到当前稿；如果预期基线稿 SHA 不符则停止。未来任何排名文本变化仍需重新核对向量与缓存，本轮结论不能外推。

默认读取 `hit`，仅包含原命中句的全部登记位置；`supplement` 返回有原文依据的同行为、责任说明或单一行为表行；`extended` 包含身份信息、含其他行为的局部原文和可选全文，不能继承命中主体。F004155 两次匹配分别保留，第七表行另有销售误导，已划入扩展。

[scope_overlays.jsonl](scope_overlays.jsonl) 保留已有 unit/case/behavior/evidence ID、当前稿 SHA、原关联、conditions/exceptions/negations 等真实候选字段与限制。`current_candidate_fields` 是整份文书的候选解释，并非每个字段都在当前 unit 中成立。新增 `FRSCOPE-SPAN-*` 只标识本覆盖层的登记区间，不替换旧证据 ID。精确原句、区间与旧 evidence ID 的交叉关系见 [spans.jsonl](spans.jsonl)。

本目录 [evidence_loader.py](evidence_loader.py) 为标准库只读样例。正式集成时把已审阅的五类版本锁冻结在调用端配置中；缺版本、错版本、未知 ID、错层、任意未注册区间和指纹不符均拒绝，不能遇错后自动接受包里的新版本。

```python
import json
from pathlib import Path
from evidence_loader import EvidenceLoader

bundle = Path("本交接包的绝对路径")
pinned_versions = json.loads((bundle / "version_lock.json").read_text(encoding="utf-8"))
loader = EvidenceLoader(bundle, expected_versions=pinned_versions)
unit_id = next(u["unit_id"] for u in loader.units.values() if u.get("file_id") == "F004090")
hit = loader.read(unit_id)
same_behavior = loader.read(unit_id, layer="supplement")
span = hit["segments"][0]
exact_quote = loader.read(span["span_id"], start=span["start"], end=span["end"])
```

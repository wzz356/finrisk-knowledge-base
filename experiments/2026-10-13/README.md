## 核验与无损恢复

所有大于20MiB载荷保存为同名目录的gzip分片与parts.json，按原行/原字节顺序恢复。清单包含原始SHA、分片SHA和字节大小；报告中的同名大JSONL链接可打开分片目录。

```powershell
python .\tools\verify_experiments.py --repo .
python .\tools\v2_payloads.py --version .\experiments\2026-10-13 --destination .\restored-experiments-20261013
```

第二条命令要求恢复目录为空，逐字节验证480载荷；它不会调用模型或改源。完整复跑还需要已发布V2/V1来源、原模型及运行依赖；本轮保留原运行时的绝对路径/SHA历史，不冒称跨机器即开即跑。按[payload_map](payload_map.json)恢复后，原outputs/work目录结构保留；模型、向量缓存、虚拟环境、教材原PDF、凭据和360预留正文均不在归档。

来源指纹/当时测试与模型审批证据均可核查。最新本轮25项必要测试、105依赖及排名/源片段核验通过，机械和字节通过不能替代全量人工语义批准。新输入应另建批次，不覆盖已冻结的16输入或继承旧意见。

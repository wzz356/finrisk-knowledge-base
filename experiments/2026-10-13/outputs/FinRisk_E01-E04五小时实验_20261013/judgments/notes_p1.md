评价范围：只按本轮评分规则、input_p1.jsonl 中的当前业务输入、完整文书和实际 context 文本重新判断。逐 pair 全文阅读，逐 context 独立阅读；分段读取索引 0–89，工具输出无截断。90 个 query/file pair 的全文各评一次，91 个实际 context 均已评价，涉及 14 段不同业务输入。

实际阅读字符数（按 JSON 解码后的 Python len 计算，保留正文换行）：全文 81,683 字符；context 18,604 字符；逐 pair 展示的 query_text 合计 5,559 字符；总计 105,846 字符。重复出现在不同 pair 的全文或输入计入实际展示阅读量，不将其声称为独立事件数量。

分数边界：0 为当前机制无帮助；1 为主题或销售渠道相关、只有笼统案由、证据类别或身份信息，缺少具体业务机制；2 为原文揭示可支撑一部分判断的具体机制或条件；3 为核心机制与必要条件、实际事实充分。公开表没有因格式而自动降分：如“直销业务虚挂中介套取费用”揭示实际与登记渠道差异，可评 2；只有“虚挂个人代理业务”且缺真实来源与套费关系仍评 1。单句“赠送合同外利益”缺具体形式、对象触发关系通常评 1；原文展示车险促销向投保人赠合同外礼品及服务可评 2；网络投保车险赠洗车券的渠道、形式及合同关系完整可评 3。

条件边界输入保留相反案例的核查价值。无损失变化却为降低年底估损而调数、删赔案，与有新损失证据且保留记录的正常重估条件相反，仍可评有用边界。已持本机构执业证与尚未发证分别判断，不以电话号码维护推出无证；历史销售资格证与机构执业证不得混同。正常真实培训费用与虚列未发生培训会议、转作渠道推动或佣金支出区分。案例处罚不自动证明当前输入违规。

全文与片段分数不互相补事实。如全文有未告知免赔期，而返回片段只含虚假宣传案由，片段仍为 1。只有证据清单、案由标题或人员身份的片段没有借用全文机制加分。分段摘录的引用只取其中一段连续原话，未拼接间隔；派生标签不作原话。洗车券及油卡赠送、费用真实问题分别判断：仅展示油卡赠送、缺宣传费入账时给部分支撑，展示宣传费购卡赠电网销投保人或被保险人时才给充分机制分。

误用警示只标具体错移用缺口：历史资格证被当成本机构发证、空气污染产品给付条件被套至重疾险、代抄或笔迹差异被当成无授权代签的充分证据、截断多主体表片段把共同案由直接归到第五位人员。未将所有弱关联、条件相反或多主体表都自动标警示。警示为模型意见，既非已确认错误率，也不意味着未警示就正确。
